SimpleAchievement Plugin - How To Use

From the devs of Hell Jump
Made by AramCZGames | Godot 4.6+

INSTALLATION

1. Copy the addons/SimpleAchievement folder into your Godot project
2. Go to Project > Plugins and enable "SimpleAchievement"
3. AchievementManager will be added as an Autoload automatically

SETTING UP ACHIEVEMENTS

Open addons/SimpleAchievement/achievements.json and define your achievements:

[
	{
		"id": "my_achievement",         <- unique ID used in code
		"name": "My Achievement",       <- shown in popup and viewer
		"description": "Do something.", <- shown in popup and viewer
		"icon": "res://icon.png",       <- path to icon (leave "" for none)
		"goal": 1                       <- 1 = instant unlock, higher = progress tracked
	}
]

UNLOCKING ACHIEVEMENTS IN CODE

Instant unlock:
	AchievementManager.unlockachievement("my_achievement")

Progress tracking (adds amount to progress, unlocks when goal is reached):
	AchievementManager.progressachievement("my_achievement", 1)

Check if unlocked:
	AchievementManager.isunlocked("my_achievement")

Get current progress:
	AchievementManager.getprogress("my_achievement")

Reset all achievements:
	AchievementManager.reset()

ACHIEVEMENT VIEWER

To let players browse their achievements, add the viewer scene to your game:
	res://addons/SimpleAchievement/ui/AchievementViewer.tscn

You can change_scene_to_file() to it or instance it inside a menu.
It automatically reads from AchievementManager and shows locked/unlocked
status and progress bars for tracked achievements.

SIGNALS

Connect to these signals on AchievementManager:
	achievement_unlocked(id: String)
	achievement_progress(id: String, current: int, goal: int)

Example:
	AchievementManager.achievement_unlocked.connect(_on_achievement_unlocked)
	func _on_achievement_unlocked(id: String):
		print("Unlocked: ", id)

SAVE FILE

Achievements save automatically to: user://achievements.save
This is completely separate from your game's save data.

NOTES

- This plugin is work in progress and will have bugs!
- Achievement IDs are case sensitive
- Calling unlockachievement() on an already unlocked achievement does nothing
- The popup slides in from the bottom left corner
- Multiple popups queue up and show one after another
- Icons are optional, leave "icon" as "" if you don't have one
