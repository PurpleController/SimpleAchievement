# SimpleAchievement
 An achievement plugin that gets your sh*t done
# What makes it so easy to use:
1. Unlike others this plugin installs to the addons folder 
2. It has a howtouse.txt to get you started
3. The ID system is not broken yay
4. You do not add the IDs like via a python script or weird ways you just add them in a JSON (Do not worry there are template achievements for you already)
5. The commands are easy to understand
6. The plugin has already a built in menu that shows you achievements
# Installation
**Via Git (recommended):**
1. Open the terminal in your addons folder in your project. (If you do not have one create one)
2. Then run this command: 
```
git clone https://github.com/AramCZGames/SimpleAchievement
```
**Manually:**
1. Download the source code of this project
2. Go to your addons folder and paste this plugin into it (If you do not have a addons folder create one)
